Troubleshooting

The error you see, and what to do about it.

1HTTP 403 from the API

403: The from address does not match a verified Sender Identity.
FIX

Verify the domain in MAIL_FROM_ADDRESS in your SendGrid or Brevo dashboard.

2401 Unauthorized

401: The provided authorization grant is invalid, expired, or revoked
FIX

Check the API key. For Brevo use the xkeysib- API key, not the xsmtpsib- SMTP password.

3Still trying port 587

Connection could not be established with host "smtp.sendgrid.net:587"
FIX

Your app still uses SMTP. Set MAIL_MAILER=sendgrid or brevo, then clear the config.

4New .env values are ignored

Config is cached, so old mail settings are still used
FIX
php artisan config:clear

5Unsupported mail transport

Unsupported mail transport [sendgrid].
FIX
composer dump-autoload && php artisan config:clear

6Queued mail never arrives

No error on screen, the job failed in the background
FIX

Check the failed_jobs table and storage/logs for a TransportException. It has the provider's real error.
